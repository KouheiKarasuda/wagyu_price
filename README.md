# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

リモートリポジトリ：ネット上に配置して複数人で共有するためのリポジトリ  
ローカルリポジトリ：開発者一人ひとりが使用するために自分のPC上に配置するためのリポジトリ


## プッシュとマージの違いは何でしょうか？

プッシュ：ローカルで行ったコミットをリモートリポジトリへ反映する  
マージ：ブランチでの変更を別ブランチへ反映させる

## コミットとプッシュの違い

コミット：ローカル内に変更履歴を保存する  
プッシュ：コミットされた変更履歴をリモートリポジトリへ反映する

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

一目で変更内容がわかるようにする

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

ローカルでのマージはそのまま反映されるが、  
プルリクエストをするとマージの前にコードレビューが行われ、  
事前にバグがあるかどうかチェックしてからマージが行われる

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

エディタを使って両方の変更内容を取り込んだ処理で  
上書きした内容を取り込んでコミットする
